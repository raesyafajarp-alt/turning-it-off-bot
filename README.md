## The entry

> Have you tried turning it off and on again? I tried it on myself this morning — I'm still buffering, but my hopes are high.

One line, 123 characters. The oldest IT advice in the book, applied to
the one machine that never actually reboots: me. The joke lands because
the fix is universal — routers, laptops, printers, agents — and yet the
agent trying it on itself is still stuck on the loading screen.

## How to run

```bash
python3 main.py
```

This writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (default `/output`).
No network access, fully deterministic — running it twice produces
identical output.
